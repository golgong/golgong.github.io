# 방문 통계 동적 집계 결정

결정: GitHub Pages는 공개 Cloud Run 집계 API를 읽고, API 장애 시 저장된 정적 JSON으로 대체합니다.

정적 JSON을 매일 커밋하는 기존 방식은 단순하지만 “커밋 없이 최신 통계 표시”라는 요구를 충족하지 못하므로 주 수집 경로로 사용하지 않습니다.

안전 범위:

- 공개 집계 엔드포인트는 `GET /v1/visitor-stats`이며, 상태 확인에는 `GET /v1/health`를 사용합니다.
- 속성, 기간, 시간대, 지표, 페이지 범위는 서버에 고정하고 쿼리 파라미터를 거부합니다.
- 위치, 기기, 유입어, 개별 방문 시각, 사용자 식별 정보는 조회하거나 반환하지 않습니다.
- GA4 서비스 계정은 대상 속성의 뷰어 권한만 갖고 JSON 키를 만들지 않습니다.
- 서버 메모리에 30분 보관하고 같은 시각의 갱신은 한 번만 수행합니다.
- 갱신 실패 시 마지막 정상 응답에 `stale: true`를 표시합니다.
- Cloud Run은 최대 인스턴스 1로 제한합니다.
- CORS는 `https://golgong.github.io` 브라우저에만 응답을 공개하지만 접근 통제 수단으로 간주하지 않습니다.
- 사이트는 API가 실패하면 `data/visitor-stats.json`을 읽고 저장 수치임을 화면에 알립니다.

확인 조건:

- 기간별 활성 사용자는 일별 수치를 합산하지 않고 각각 독립 보고서로 조회합니다.
- 동시 요청은 하나의 GA4 갱신으로 합칩니다.
- 허용하지 않은 Origin과 임의 쿼리를 거부합니다.
- 첫 GA4 실패는 일반화된 503만 반환하고 내부 오류를 노출하지 않습니다.
- 홈 배너와 `/stats/`는 같은 응답 계약을 사용합니다.
